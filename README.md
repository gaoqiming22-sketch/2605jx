# 2605 · 军训纪（军训过程记录 → 纪念册）

武汉理工大学物理与力学学院 · 电子信息类2605班，军训期间的“时间流记录”项目：每天把当天发生的事说给 Codex，逐条沉淀；军训结束时一键生成 **单文件 HTML 纪念册 + 一张总长图**，发 QQ 群一次。

## 怎么打开预览（不用命令行）
- 双击本文件夹里的 `index.html`，即可看到当前的时间流纪念册（纯本地、零依赖、不上网）。
- 内容全部来自 **`js/data.js`（唯一数据源）**：改完刷新浏览器就是最新版。

## 怎么记录（每天约 1 分钟）
1. 军训结束后，直接跟 Codex 说当天情况，例如：
   - “今天练了正步，下午会操预演，XX 顺拐被教官点名了……”
   - “今天下雨在室内学军歌，晚上拉歌特别嗨。”
   - “今天拍了张合影，在桌面/发给你的文件里，帮我放进去。”
2. Codex 会把你说的整理成一条结构化记录，**追加/更新**到 `js/data.js`（同一天重复说只更新当天那条，不会重复）。
3. 有照片时：告诉 Codex 照片位置，或自己把照片放进 `assets\photos\`（命名建议 `day-01-描述.jpg`）。
4. 完成后刷新 `index.html` 确认。
5. 中途换新对话也不丢数据——一切都在 `js/data.js`。

## 军训结束怎么生成成品
告诉 Codex“生成成品”，或手动运行：
```
node scripts/build.mjs
```
产物在 `dist\` 文件夹：
- `2605军训纪念册.html`：**单文件自包含**（照片已内联成 base64，断网也能开），双击/手机浏览器都能看，作为完整版发群文件或存群文件/网盘。
- `2605军训总长图.png`：宽 1080 的纵向长图，**群里先发这张**，人人点开就能看。
- `长图.html`：生成长图用的中间页，不用上传，可忽略/删除。

发群建议：长图直接发群里；HTML 完整版可同时发群文件（二选一由你定）。

## 数据字段速查（js/data.js）
- `meta`：标题 / 学校 / 学院 / 班级 / 作者 / 职务 / start / end（军训起止日期，结束后回填）/ logo / buildAt
- `intro`：开营寄语（一段）
- `days[]`：每天一条——`day`(自动=顺序号) `date`(YYYY-MM-DD，可后补) `weather`(可选) `title` `tags[]`(如 开营/拉练/会操/结营) `paragraphs[]`(2~4段) `quote`(可选金句) `photos[]`(可选，`file` 填相对项目根路径，`caption` 一句话)
- `gallery[]`：结尾照片墙（结营合影等，可选）
- `closing`：结营感言

## 隐私与安全
- 纯本地个人项目，不发布公网、不联网上传。
- 只写名字等非敏感信息；不要把学号、电话、身份证号写进 `data.js`。
