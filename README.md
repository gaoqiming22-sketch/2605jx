# 2605 · 军训纪（五模块网页版）

武汉理工大学物理与力学学院 · 电子信息类2605班，军训记录 **网页版**：顶部五个模块点着看，手机电脑都好开；军训期间每天把当天情况说给 Codex，逐条沉淀；结束时把网页发布成网址发到 QQ 群。

## 五个模块（顶部页签）
| 模块 | 看什么 |
|---|---|
| 总览 | 封面、军训进度、统计（天数/语录/趣事/照片）、最近一天、结营感言 |
| 每日记录 | 每天一条完整时间流（正文+金句+趣事+照片） |
| 语录·趣事 | 自动汇总所有金句语录、趣事名场面 |
| 照片墙 | 自动汇总所有照片（每天照片 + 结营合影） |
| 安排·通知 | 作息/阶段安排 + 需要转达的通知 |

- 纯本地、零依赖、不上网；手机电脑都能看。

## 怎么记录（每天约 1 分钟）
1. 训练结束后直接跟 Codex 说当天情况，例如：
   - “记录军训：今天练了正步，下午会操预演……”
   - “XX 顺拐被点名（趣事）、教官说‘站军姿核心是坚持’（语录）”
   - “通知：明早 7:20 集合，帮我加进安排·通知”
2. Codex 会整理成一条结构化记录，追加/更新到 `js/data.js`（同一天重复说只更新当天那条）。
3. 有照片：告诉我照片位置，或自己放进 `assets\photos\`（命名 `day-01-描述.jpg`），照片墙会自动汇总。
4. 完成后刷新页面确认；换新对话也不丢数据（一切在 `js/data.js`）。

## 军训结束怎么发到 QQ 群（手机电脑都能打开）
1. 内容定稿后对 Codex 说“生成成品/发布”，它会：
   - 生成 `dist\2605军训纪念册.html`（单文件自包含网页，可作离线备份）+ `dist\2605军训总长图.png`（可选备份）；
   - 把网页发布到 **GitHub Pages**（需要你的 GitHub 账号登录一次，联网），得到一个网址，如 `https://你的用户名.github.io/2605jx/`。
2. 把网址发到 QQ 群，同学在手机/电脑浏览器里点开就是网页。

## 数据字段速查（js/data.js）
- `meta`：标题/学校/学院/班级/作者/职务/start/end/logo/buildAt
- `overview`：slogan(开营寄语)/place/team/note —— 显示在总览
- `schedule[]`：`{period, items[]}` —— 作息/阶段安排
- `notices[]`：`{date,title,text,src}` —— 通知；含“待核实/以…为准”会自动加橙色标记
- `days[]`：每天一条 `{day,date,weather,title,tags[],paragraphs[],quotes[],fun[],photos[]}`（date 可后补）
- `gallery[]`：额外大合影（每天照片会自动进照片墙，无需重复放）
- `closing`：结营感言（总览底部）
